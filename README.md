# STREET WOMAN

Site vitrine de **STREET WOMAN**, une galerie de street art féministe à Nice.
L'art dans la rue. Les femmes au centre.

## Contenu

- `index.html` : la page du site (accueil, images du moment, galerie, événements, contact)
- `style.css` : la feuille de style
- `images-sw/` : les images et le logo du site
- `LISEZ-MOI_SEO.txt` : notes sur le référencement et points à vérifier avant la mise en ligne

## Voir le site

Ouvrir `index.html` dans un navigateur.
