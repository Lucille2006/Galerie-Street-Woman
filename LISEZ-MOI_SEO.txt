# STREET WOMAN — Site avec optimisations SEO

Le dossier contient :
- `index.html` : page du site avec les optimisations SEO intégrées.
- `style.css` : feuille de style d'origine, conservée.

## Optimisations SEO intégrées
- Balise `<title>` plus précise avec le nom du site, l'activité et la ville.
- Meta description reformulée avec les mots-clés principaux, sans accumulation artificielle.
- Indication de la langue et de la catégorie du site.
- Données structurées Schema.org enrichies avec des mots-clés liés à l'activité.
- H1 plus descriptif et intégration naturelle de termes recherchés dans le texte d'accueil.
- Conservation des balises Open Graph et Twitter Cards pour le partage sur les réseaux sociaux.
- Conservation des textes alternatifs (`alt`) descriptifs sur les images.
- Conservation des optimisations de chargement des images et des polices.

## À vérifier avant la mise en ligne
1. Remplacer `https://www.streetwoman-galerie.fr/` par l'adresse réelle du site dans les balises `canonical`, Open Graph, Twitter et les données structurées.
2. Vérifier que les coordonnées, l'adresse, l'e-mail, le téléphone et les dates d'événements sont exacts et réellement utilisés.
3. Ajouter dans le dossier le répertoire `images-sw` avec toutes les images appelées dans le HTML. Il n'était pas présent parmi les fichiers transmis.
4. Vérifier que le formulaire de contact est relié à un service ou à un serveur : avec `action="#"`, il ne transmet pas réellement les messages.
5. Une fois le site publié, créer et soumettre un sitemap XML dans Google Search Console.

Remarque : le fichier CSS a été conservé sans modification, car le référencement naturel se travaille principalement dans le contenu HTML, la structure, les métadonnées et les performances.
